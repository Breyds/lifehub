# LifeHub — зміни

## 0.5.2 — Календар, фото новин, YouTube та ДТЕК

- Числовий бейдж у календарі лише для **критичних/термінових** справ; інші залишаються у вікні дня.
- У вікні дня окремі розділи: критичні, важливі, повторювані та звичайні.
- «Усі справи»: датовані групи зі вкладеною пріоритетністю й повторюваністю.
- YouTube Trend Radar: реальне посилання на відео й канал для результатів офіційного API; без API — чесні RSS-статті без вигаданих переглядів.
- Фото новин: спроба витягти оригінальне `og:image` для довірених сайтів, а потім зображення конкретно названої теми з Wikipedia з підписом.
- Графік ДТЕК: збереження адреси, запит на адресу через вбудований захищений браузер / `/ua/ajax`, розбір лише підтверджених часових слотів, показ результату всередині LifeHub та оновлення під час роботи. У разі блокування або неоднозначності дані не вигадуються.

### Перевірки

- Unit tests: 65/65.
- Syntax: Node Electron module check + TypeScript JSX transpilation.
- Не перевірено: робота DTEK на реальному сайті для твоєї адреси, TypeScript typecheck та Windows Electron EXE; ці кроки виконуємо через GitHub Actions і тест на ПК.

### Безпека

- Особиста адреса зберігається локально. У GitHub її не відправляємо.
- Секрети Telegram, AudD, YouTube, OpenAI не входять у вихідний архів та не повинні потрапляти в репозиторій.
