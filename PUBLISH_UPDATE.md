# Як оновити твій встановлений LifeHub з 0.2.0 на 0.3.0

> Ти вже маєш репозиторій `https://github.com/Breyds/lifehub` та встановлену 0.2.0. Створювати репозиторій заново або видаляти LifeHub НЕ потрібно.

## 1. Збережи дані

В установленій LifeHub 0.2.0 натисни **Налаштування → Експортувати JSON**. Збережи копію на ПК. Не публікуй особисті дані у GitHub.

## 2. Перенеси код

1. Розпакуй **LifeHub-v0.3.0-Source.zip** у тимчасову папку.
2. Знайди свою ПОПЕРЕДНЮ папку проєкту, з якої відправляв `git push` (наприклад `Downloads\LifeHub-v0.2.0-Windows-Source\LifeHub`).
3. Перенеси **весь вміст** нової папки `LifeHub-v0.3.0` у ту стару папку з файлом `package.json`. Погодься замінити однойменні файли. **Не видаляй стару папку `.git`!** В архіві її немає.
4. У старій папці знайди `package.json` і перевір, що там тепер `"version": "0.3.0"`.

## 3. Перевір і відправ

У цій же папці через адресний рядок провідника введи `cmd`. Перевір:

```bat
git status --short
npm test
npm install
npm run build
```

Якщо `npm run build` дає помилку, **не став тег і не публікуй реліз**. Скинь помилку в наш чат.

Якщо все успішно:

```bat
git add .
git commit -m "LifeHub Studio 0.3.0"
git push origin main
git tag v0.3.0
git push origin v0.3.0
```

Якщо `git tag v0.3.0` каже `already exists`, повідом про це, не створюй навмання інший тег.

## 4. GitHub Actions

Зайди на `https://github.com/Breyds/lifehub/actions` і знайди запуск для тега v0.3.0. Після успішної збірки відкрий `https://github.com/Breyds/lifehub/releases`. Якщо реліз позначено Draft, відкрий редагування та натисни Publish release.

Після публікації 0.3.0 твоя встановлена версія 0.2.0 зможе перевіряти новий реліз. Вона пропонує підтвердження установки; якщо автоматичне оновлення видасть помилку (можливе через непідписані збірки), завантаж `LifeHub-Setup-0.3.0.exe` і встанови поверх поточної версії. Дані зберігаються в Windows профілі, а не в папці інсталятора.

## 5. Як переконатися, що оновлення встановлено

Відкрий LifeHub — у боковій панелі повинні з'явитися **Плани, Проєкти, Реальні тренування, CS2, YouTube, Стріми, Новини, Музика**. У «Налаштуваннях» — новий блок «Оформлення й персоналізація».

**Важливо:** написати мені про зміну ≠ автоматично оновити програму. Потрібно, щоб новий код потрапив у GitHub та GitHub Actions випустив реліз. Встановлений LifeHub тоді сам знайде готову версію.
