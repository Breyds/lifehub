# LifeHub 0.2.0 — Personal Edition

Персональний Windows-планувальник із AI-пропозиціями, які **застосовуються тільки після підтвердження користувача**. Першочерговий сценарій — один користувач, дані на його комп’ютері.

## Що нового у 0.2.0

- Нова тема Aurora (перероблений стартовий екран, кольорові картки, навігація).
- Підготовлена система **автоматичних оновлень через GitHub Releases**. Потрібно виконати перший реліз. Перевірка після запуску й кожні 6 годин; завантаження без ручного пошуку інсталятора, **установлення тільки після підтвердження перезапуску**.
- Вкладка **Імпорт ChatGPT** — читання `conversations.json` із ZIP-експорту, локальний відбір повідомлень за ключовими темами; відправка тільки вибраних повідомлень у OpenAI для пропозицій, а не автоматичне додавання старих планів.
- Вкладка **Rank It Studio** — папка `Відео/LifeHub Inbox`, сканування відеофайлів, імпорт MP4/MOV/M4V/WebM і створення локальних чернеток (назва, опис, час).
- Валідація даних імпорту та локальні модульні тести.
- Збережено попередні можливості: завдання, повтори, нагадування (поки застосунок працює), статистика, шифроване зберігання API-ключа на Windows, приблизний лічильник AI-витрат.

### Важливо: що **ще не готове**

1. **Готового `.exe` у цьому архіві немає.** Він збирається на Windows командою `npm run dist:win` або автоматично в GitHub Actions після налаштування репозиторію. Роботу на реальній Windows-машині треба перевірити.
2. **Оновлення ще не роздаються**: потрібні публічний GitHub Releases feed і перша збірка, опублікована з реальною адресою власника й репозиторію.
3. OpenAI API **не дає LifeHub права автоматично читати всі вкладення ChatGPT**. Ролики з ChatGPT наразі потрібно один раз зберегти в Inbox або вибрати через «Додати відео».
4. **Жодне відео не завантажується на YouTube**. Офіційний YouTube Data API (OAuth 2.0, `videos.insert`, підтвердження публікації) — запланована наступна інтеграція.
5. LifeHub **не змінює свій код після повідомлення в чат**. Нову версію треба реалізувати, протестувати, зібрати та опублікувати в GitHub Releases. Після цього встановлений LifeHub може отримати оновлення.

## Перша установка на Windows

1. Встанови [Node.js LTS](https://nodejs.org/).
2. Розпакуй проєкт **один раз** і виконай у PowerShell:

```powershell
npm install
npm test
npm run build
npm run dist:win
```

3. Шукай `release/LifeHub-Setup-0.2.0.exe`. Установи програму. Це Windows installer (NSIS), дані розташовані в профілі користувача, а не в папці інсталяції.
4. Для перевірки інтерфейсу без інсталятора: `npm run dev`.

> Важливо: не тестовано встановлення `.exe` у Windows у поточному середовищі. Без підпису Windows SmartScreen може показати попередження про невідомого видавця.

## Налаштування автооновлень

Дивись **[RELEASE_WINDOWS.md](RELEASE_WINDOWS.md)**. Коротко: створи GitHub-репозиторій, додай проєкт, створюй нові Git-теги `v0.2.0`, `v0.2.1`, ...  GitHub Actions збере й опублікує `.exe`, `latest.yml`, `.blockmap` у Releases. Встановлений застосунок дізнається про нову версію автоматично. GitHub Releases має бути доступним без авторизації з твого комп’ютера, тобто для простого сценарію публічний репозиторій. **Не коміть свої ключі API і особисті дані.**

## Підключення AI ($5 бюджет)

- На [OpenAI Platform](https://platform.openai.com/) створи окремий проєкт LifeHub та **персональний** секретний ключ; збережи його через меню LifeHub → Налаштування.
- Установи в налаштуваннях API-проєкту бюджет $5 та, якщо доступне, примусове обмеження. Облік LifeHub локальний та орієнтовний, не враховує інші клієнти й зміну цін; витрати можуть перевищити ліміти через затримку обліку.
- LifeHub використовує `gpt-5-mini` через Responses API. Тільки підтверджені тобою AI-пропозиції змінюють завдання.
- Ключ на Windows зберігається шифровано через Electron `safeStorage`. **Нікому не надсилай сам ключ і не вставляй його в ChatGPT.**

## Імпорт чатів

1. У ChatGPT: Settings → Data controls → Export data. Завантаж ZIP, коли прийде посилання.
2. Розпакуй ZIP і вибери `conversations.json` у вкладці LifeHub **Імпорт ChatGPT**.
3. Переглянь знайдені фрагменти. Вибери **до 12** повідомлень для AI-аналізу (вибраний текст надішлеться в OpenAI). Решта файлу лишається локально.
4. AI запропонує до 8 змін, ти вибираєш, які підтвердити. Старі чати **не вважаються актуальним розкладом автоматично**.

Імпорт обмежено до 200 МБ для `conversations.json` і показує до 120 релевантних повідомлень; це перша версія відбору. Нічого з ChatGPT не синхронізується автоматично.

## Rank It Studio

- Відкрий вкладку **Rank It Studio → Відкрити папку Inbox**.
- Збережи MP4/MOV/M4V/WebM із ChatGPT у цю папку (або натисни «Додати відео», щоб скопіювати його з іншої папки).
- Відкрий чернетку, відредагуй назву, опис, бажаний час і збережи локально. Inbox оновлюється кожні 25 секунд, поки відкритий цей розділ.
- Автопублікація на YouTube буде окремим кроком після авторизації твого каналу OAuth 2.0 та тестування безпечних публікацій.

## Дані та приватність

- Зберігання — локальний JSON (`app.getPath('userData')/lifehub.json`), із резервним копіюванням задач у JSON з налаштувань.
- AI-запити включають текст поточного звернення та до 60 завдань; для імпорту — тільки вибрані повідомлення. Відправка відбувається **після натискання відповідної кнопки**.
- Для Inbox відео лежать у папці `Відео/LifeHub Inbox`, а метадані чернеток зберігаються локально в профілі.
- Нагадування працюють, **коли LifeHub запущено**; автозапуск треба ввімкнути після інсталяції.
- Поки немає імпорту резервної копії або хмарної синхронізації; не видаляй папку профілю, якщо там важливі завдання.

## Перевірка


### Структура

- `src/main.tsx` — основний інтерфейс.
- `src/ExtraPages.tsx` — ChatGPT Import, Rank It Studio, Updates.
- `src/style.css` — Aurora UI.
- `electron/main.cjs` — застосунок, зберігання, API, обновлення, імпорт, IPC.
- `electron/chat-import.cjs` — локальний парсер експорту ChatGPT.
- `electron/video-inbox.cjs` — папка Inbox і перевірка відео.
- `electron/preload.cjs` — ізольований міст до UI.
- `.github/workflows/windows-release.yml` — GitHub Actions для Windows installer + Release.
- `RELEASE_WINDOWS.md` — детальна інструкція з публікації.
