# LifeHub 0.4.1 — Personal Edition

**Windows / Electron / React / TypeScript** · дані локально · AI лише за твоїм підтвердженням.

Це **вихідний код**, а не встановлювальний EXE. Збирай через GitHub Actions після перевірки `main`.

## Ще НЕ готове

- Автоматичне завантаження/публікація відео в YouTube. Для цього потрібна авторизація Google OAuth і розробка повноцінного завантажувача.
- Реальна аналітика каналу, CTR, утримання, статистична модель прогнозування успіху відео.
- Автоматичний доступ до приватних TikTok «Збережених», сканування колекції та Shazam-розпізнавання аудіо просто за посиланням. URL-колекції **лише зберігається**.
- Розбір файлів `.dem` CS2 (потрібен парсер демо, недостатньо відправити бінарний файл в AI).
- Автоматичний переклад усіх новин за розкладом (переклад тільки за натисканням).
- Повністю випробуваний EXE для 0.4.0 — перевіряється GitHub Actions і далі на твоєму Windows.

## Приватність і витрати

Завдання/профіль/журнали/музика зберігаються на ПК у `lifehub.json` у теці даних програми. API-ключ зберігається зашифрованим через Electron `safeStorage`; резервна копія **не містить** ключа. AI-запити й вибрані фото надсилаються в OpenAI тільки після натискання користувачем відповідної кнопки. Фото для оцінки калорій відправляється у зменшеному розмірі; його результат не записується до журналу, поки користувач не підтвердить.

Ліміт $5 в UI — **локальна оцінка**, а не абсолютний фінансовий захист. Налаштуй окремий API-проєкт і обмеження витрат у своєму кабінеті OpenAI. API оплачується окремо від ChatGPT Plus. Іноді місцевий облік може відрізнятися від остаточного білінгу API.

AI-тренер не є лікарем/дієтологом. Фото не дозволяє достовірно визначати вагу, масло чи інші невидимі інгредієнти. Дефіцит калорій і навантаження підбираються поступово, з урахуванням здоров’я.
