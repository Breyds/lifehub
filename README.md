# LifeHub 0.3.1 — Studio Edition (build fix)

Windows desktop app (Electron + React + TypeScript) для особистих планів, проєктів, YouTube, стрімів, тренувань, музики і новин. Дизайн перероблений на темний графітовий із налаштовуваним акцентом, без гігантських декоративних банерів. **Не плутай цей архів з інсталятором: це вихідний код для випуску оновлення.**

## Що реалізовано в 0.3.1

- **Сьогодні** — чекліст, відмітки виконання, локальні сповіщення, AI-планування лише після твого підтвердження (успадковано з 0.2).
- **Плани** — календар на місяць/тиждень, прив'язка локальних задач до дат.
- **Проєкти** — окремі записи великих цілей з описом, етапами, дедлайном, ручним прогресом і статусом.
- **Тренування → Фізична форма** — журнал силових тренувань, ходьби/кардіо, харчування, маси тіла, програми та базовий спортивний профіль. Кожен запис додається/редагується/видаляється. AI за окремим натисканням може запропонувати текстовий план, який ти перевіряєш і зберігаєш.
- **CS2** — журнал занять з аіму/DM/демок/матчів та часом.
- **YouTube** — список каналів із URL, робочий контент-план з етапами, ручна черга відео Inbox (з 0.2), добірка потенційних тем із новин RSS, окремий AI-аналіз заголовків.
- **Стріми** — розклад, сценарії, зв'язок з існуючими проєктами, перенесення підготовки в календар задач.
- **Новини** — до 5 категорій (аніме, ігри, інтернет, світ, технології), Google News RSS, ручне оновлення, автоматичне оновлення після запуску (не частіше одного разу на 24 години), оцінки «Цікаво»/«Не цікаво», локальне сортування відповідно до категорій і свіжості, кнопка додавання теми до календаря. Немає платного AI при звичайному оновленні новин. Доступність стрічок залежить від інтернету й RSS провайдера.
- **Музика** — список пісень і TikTok-посилань, статус додано/ще чекає, CSV-експорт, п'ятничне нагадування, коли програма запущена.
- **Навчання** — базові задачі й дедлайни із попередньої версії.
- **Налаштування** — зелений/синій/фіолетовий/помаранчевий акцент, компактність, вибір тем новин, музичне нагадування, англійська навігація у режимі beta (інші частини інтерфейсу наразі українські).
- **Імпорт ChatGPT та автооновлення** — механізми з 0.2 залишились.

Нові дані зберігаються в `workspace` усередині того самого локального `lifehub.json`. Старі `tasks`, `videoDrafts`, OpenAI API налаштування залишаються. **Оновлення ніколи не повинно вимагати перевстановлення чи видалення даних.** Перед першим оновленням зберегти резервну копію через інтерфейс програми — хороша практика.

## Що НЕ реалізовано, щоб не обманювати користувача

- Автоматичне отримання відео/файлів із **усіх чатів ChatGPT**, як і раніше, **не підтримується**. Користувач завантажує готове відео в Inbox.
- Автоматична публікація в YouTube/Shorts, реальні перегляди/CTR/retention каналів — **не готові**. Потрібен Google OAuth + YouTube Data API / Analytics API, тестування з твоїм акаунтом і підтвердження кожного завантаження.
- Прямий доступ до TikTok «Збережене» або автоматичне визначення назви пісні лише за URL — **не готові**. Існують обмеження офіційних API. Наявний варіант — ручне додавання TikTok-посилання/назви та експорт списку.
- Автоматичне додавання до Spotify — **не готове**. Для нього знадобиться Spotify OAuth/PKCE, із дозволом на редагування плейлиста.
- Об'єктивна «формула успішності Shorts» **не готова**: новинні заголовки не є статистикою переглядів, а оцінки в стрічці — локальна проста евристика, не ML-модель. Лише підключення реальних аналітичних метрик і історії роликів дозволить тестувати рейтинг.
- Вбудований AI не шукає новини на власний розсуд за розкладом. Новини безкоштовно підтягуються через RSS, а аналіз AI запускається вручну (щоб не витрачати бюджет без попередження).
- Фоновий сервіс не працює, коли програма повністю закрита. Автооновлення новин і сповіщення здійснюються, коли LifeHub запущений.

## Безпека та витрати

- Локальна база — JSON у `app.getPath('userData')` з обережним збереженням через тимчасовий файл, не синхронізується в хмару. Тренування, вага, їжа та інші приватні записи залишаються локальними.
- AI отримує контекст цих розділів **тільки після натискання кнопки запиту**. Звичайне відкриття програми AI не викликає.
- OpenAI API ключ зберігається зашифрованим через Electron safeStorage; **не додавай його до репозиторію**.
- GPT-5 mini, локальна орієнтовна оцінка вартості, захисний поріг перед $5. Це **не жорсткий платіжний ліміт**: налаштуй бюджет/обмеження окремо на OpenAI Platform. Якщо ціна моделі зміниться, оцінку треба оновити.
- AI-тренер — не медична послуга. Безпечність вправ/раціону потрібно перевіряти; враховуй травми та інші обмеження і за необхідності консультуйся з фахівцем.
- Новини беруться з публічних RSS-стрічок, можуть бути недоступні або помилкові; уважно перевіряй першоджерела.

## Як отримати EXE і автооновлення

Для оновлення з невдалої версії 0.3.0 читай **FIX_0.3.1.md** або **PUBLISH_UPDATE.md**. Випускай **новий тег `v0.3.1`**, а не повторно `v0.3.0`. GitHub Actions має створити `LifeHub-Setup-0.3.1.exe` та `latest.yml`. Опублікуй 0.3.1 як реліз. Якщо автооновлення не спрацює, встанови новий інсталятор поверх старого.

## Перевірки

```powershell
npm install
npm test
npm run build
npm run dev
```

- **15 із 15 модульних тестів пройшли** в середовищі розробки.
- TypeScript / JSX синтаксис перевірено, додатково виконана статична перевірка типів із заглушками відсутніх залежностей.

- **Повну збірку Vite/Electron та Windows-інсталяцію 0.3.1 не перевірено**: у середовищі не працювало встановлення npm-залежностей. GitHub Actions на Windows має виконати ці кроки з реальними пакетами.
