# LifeHub 0.5.1 — приватний персональний помічник

У цій версії додано:

1. **Календар:** числовий лічильник справ на даті. Натискання на дату відкриває діалог із часом, пріоритетом, нотатками та переходом до редагування. Працює також у календарі навчання.
2. **Telegram Personal Bot:** новий токен BotFather перевіряється через `getMe`, після цього генерується короткочасний шестизначний код `/link 123456`. LifeHub приймає команди тільки від прив'язаного private chat ID, використовує `getUpdates` і `sendMessage`, шифрує токен локальним Electron safeStorage. Команди: `/help`, `/today`, `/tomorrow`, `/add HH:MM Назва`, `/done N`. При закритій програмі бот не працює.
3. **TikTok / AudD Windows (експериментально):** після натискання «Розпізнати звук» LifeHub на короткий час запитує дозвіл на захоплення системного звуку (Windows), відкриває вибране TikTok-відео, записує 16-секундний WebM Opus-фрагмент і передає його до AudD для визначення назви та виконавця. Ні аудіо, ні відео в папку не завантажується. Якщо сайт не відтворює звук, розпізнавання не відбудеться; можна вибрати локальний файл.
4. **ДТЕК:** поля населений пункт / вулиця / будинок у налаштуваннях. Зберігаються у `lifehub.json`. Є перехід на офіційний сайт для ручної перевірки; автоматичний парсер графіка поки не реалізований.

## Як встановити

Див. `UPDATE_0.5.1.md`. Не став тег версії до успішного GitHub Actions `Validate LifeHub`.

## Перевірки

У середовищі розробки успішні 56 модульних тестів, перевірений синтаксис файлів Electron та TypeScript/JSX. Повний `npm run build` не перевірений: встановлення npm-залежностей недоступне. Результат залежить від Windows CI та тесту на ПК.

## Приватність

Не передавай ботовий токен у повідомленнях, у тому числі в ChatGPT. Якщо токен уже було показано, відклич його через BotFather і створи інший. Реєстрація інших користувачів у боті цією версією **не підтримується**.
