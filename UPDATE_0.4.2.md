# Оновлення LifeHub до 0.4.2

## Що виправлено

1. Скролбари Windows: тонкі й темні, з окремою стилізацією смуги головного вікна та меню.
2. Новини: «Не цікаво» приховує новину одразу (оптимістично), реакція зберігається. «Приховані» → «Повернути» відновлює її. Вподобання враховують категорію і теми заголовків.
3. Новини: тематична ілюстративна картка, якщо фото з RSS відсутнє або не завантажилося; «Показати ще» для великих стрічок; музика лишається у розділі «Музика».
4. TikTok: кнопка «Перевірити зараз» для URL. Публічні окремі відео перевіряються через офіційний oEmbed; колекції «Збережене» не можна отримати за одним посиланням цим API — програма прямо це повідомляє. Немає автоматичного Shazam або імпорту роликів із колекції.
5. Spotify: кнопка **пошуку треку** у Spotify, не гарантоване пряме посилання на точну версію композиції.

## Як оновити

1. У встановленому LifeHub відкрий **Налаштування → Експортувати JSON**; збережи резервну копію.
2. Розпакуй `LifeHub-v0.4.2-Source.zip` і скопіюй **усі файли та папки** у свою робочу теку Git-проєкту `LifeHub`, із заміною. **Не видаляй `.git`, `node_modules` і особисту базу застосунку.** Не додавай персональних резервних копій чи API-ключів до Git.
3. Відкрий PowerShell у теці з `package.json`:

```powershell
npm install
npm test
npm run build
```

4. Якщо перевірки успішні:

```powershell
git add .
git commit -m "LifeHub 0.4.2: news, scrollbars, TikTok checks"
git push origin main
```

5. На https://github.com/Breyds/lifehub/actions перевір **Validate LifeHub** для останнього коміту. **Не створюй тег при червоній перевірці.**
6. Якщо перевірка зелена:

```powershell
git tag v0.4.2
git push origin v0.4.2
```

7. Після успішної `Build and publish LifeHub Windows` відкрий https://github.com/Breyds/lifehub/releases та опублікуй Draft `v0.4.2`, перевір `LifeHub-Setup-0.4.2.exe` і `latest.yml`.
8. Перевір LifeHub → **Налаштування → Перевірити оновлення**. Якщо автоматичне оновлення непідписаного інсталятора не спрацює, закрий LifeHub і встанови EXE поверх поточної версії без видалення даних.

## Важливо

Цей архів містить **код**, не готовий EXE. Модульні тести та перевірка синтаксису TSX проходять; повну збірку з npm-залежностями тут перевірити не вдалося (мережеве встановлення не завершилось). Збірка на Windows/в GitHub Actions — обов'язкова перевірка.

Твій OpenAI API-ключ не потрібен для перегляду новин, реакцій, Spotify-пошуку чи перевірки публічних TikTok-URL. Інтернет потрібен для RSS, Spotify та TikTok oEmbed.
