# LifeHub 0.4.3: оновлення з 0.4.2

## Перед роботою
1. У LifeHub експортуй резервну копію через Налаштування → Мої дані. API-ключ не входить до копії.
2. Збережи в безпечному місці свій каталог Git-проєкту й переконайся, що `.git` на місці.
3. Розпакуй ZIP версії 0.4.3 у цю папку з заміною файлів, але **не видаляй `.git`**.

## Перевірка до публікації
У PowerShell у папці LifeHub:

```powershell
npm install
npm test
npm run build
```

Якщо хоча б одна команда завершилась із помилкою, **зупинися й не створюй тег**.

```powershell
git add .
git commit -m "LifeHub 0.4.3 music and collection scan"
git push origin main
```

Переконайся, що **Validate LifeHub** зелений на https://github.com/Breyds/lifehub/actions .

```powershell
git tag v0.4.3
git push origin v0.4.3
```

Після успішної Windows-збірки опублікуй чернетку релізу https://github.com/Breyds/lifehub/releases . Перевір, що в Assets є EXE, `latest.yml` та `.blockmap`. Далі спробуй оновити LifeHub з установленої версії. Якщо автоматичне оновлення не працює, встанови **новий EXE поверх старого** після експорту даних.

## Перевірка музики
1. Зайди в Музика → Оновити чарти. У режимі «Вийшли за 7 днів» з'являться треки з топ-100 і нових популярних альбомів, якщо джерела віддають актуальні дані. Кількість не гарантована.
2. Встав URL колекції TikTok. Можна повний URL із `/collection/` або скорочений `vt.tiktok.com/...`.
3. Натисни «Перевірити зараз». LifeHub відкриє окреме вікно TikTok, спробує прочитати картки публічно доступних відео і повернути список у вкладку «Музика».
4. Якщо TikTok вимагає авторизацію, його сторінка може бути недоступна або не віддавати відео. Жодних гарантій автоматичного читання стороннього сайту немає. У такому випадку користуйся повним URL або додавай окремі посилання на відео.
5. Spotify відкривається пошуком, а не гарантує точного збігу. Для Shazam-подібного розпізнавання потрібен окремий сервіс аналізу аудіо; цей реліз не проводить його.

## Безпека
- У вбудованому TikTok-вікні вимкнені Node.js та доступ до API LifeHub; URL обмежені доменами TikTok.
- Не зберігай паролі TikTok або сторонні API-ключі в чаті чи репозиторії.
- `OpenAI API` не витрачається для TikTok-перегляду й Apple Music чартів.
