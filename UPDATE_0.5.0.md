# LifeHub 0.5.0 — Smart Assistant: інструкція

Це **архів із вихідним кодом**, а не готовий EXE. Потрібно зібрати Windows-інсталятор через GitHub Actions. Поки що повна збірка Windows не підтверджена.

## Що додано

1. **Telegram** — повідомлення про заплановані завдання та підсумок дня. Токен у зашифрованому сховищі Windows; створення бота через @BotFather, `/start` у чаті бота, токен вводиться тільки у LifeHub → Налаштування. Тестова кнопка. Надсилання працює тільки коли LifeHub запущений.
2. **Розпізнавання музики AudD** — окремий ключ AudD у Налаштуваннях. Кнопка біля TikTok-відео дозволяє **вибрати локальний аудіофрагмент** (MP3/M4A/WAV) і визначити назву/виконавця. Кнопка додавання результату в музичну чергу. **Автоматичне отримання аудіо з колекції TikTok не реалізоване.** AudD оплачується/лімітується окремо від OpenAI API.
3. **YouTube Trend Radar** — окремий Google Cloud YouTube Data API v3 key для публічної статистики. Багато категорій (ігри, GTA, аніме, меми, стрімери, технології, спорт, кіно). Для публічних роликів показуються перегляди, приблизні перегляди/добу й лайки. Це вибірка за запитами, не загальний рейтинг чи гарантована формула вірусності. Дані кешуються для економії квоти.
4. **Графік відключень** — ручні проміжки поточного дня, наприклад `09:00-12:00, 16:00-19:00`. AI отримує їх як обмеження під час пропозицій планів. Автоматичного зчитування від оператора поки немає.
5. **Оцінка часу** — поле тривалості в завданнях і сумарний залишок хвилин на головній сторінці.
6. **Ілюстрації новин** — наявні RSS-фото лишаються; якщо відсутні та заголовок точно містить назву відомої гри/аніме/бренду, програма пробує показати підписане зображення з Wikipedia. Це ілюстрація теми, не фотографія події.
7. **Автооновлення** — після підтвердження встановлюється тихо (NSIS `quitAndInstall(true,true)`) з перезапуском. На окремих конфігураціях Windows можливі системні запити UAC. Перевірити саме автооновлення зможемо при наступному релізі.

## Оновити свою локальну папку Git-проєкту

1. У встановленому LifeHub виконай експорт резервної копії.
2. Розпакуй ZIP у папку LifeHub з `.git`. Заміняй файли, але **не видаляй `.git`**. Не завантажуй у GitHub API-токени, експорти історії, відео чи особисті резервні копії.
3. PowerShell у цій папці:

```powershell
npm install
npm test
npm run build
```

4. Лише якщо немає помилок:

```powershell
git add .
git commit -m "LifeHub 0.5.0 Smart Assistant"
git push origin main
```

5. Перевір `Validate LifeHub` на https://github.com/Breyds/lifehub/actions. **Не створюй тег, якщо перевірка червона.**
6. Якщо перевірка зелена:

```powershell
git tag v0.5.0
git push origin v0.5.0
```

7. Перевір збірку Windows і опублікуй Draft на https://github.com/Breyds/lifehub/releases. У встановленому LifeHub перевір оновлення.

## Важливі обмеження

- Не вдається гарантувати назву пісні за посиланням на TikTok: потрібен аудіофрагмент та успішне розпізнавання AudD.
- Надсилання повідомлень із ПК **не працює при вимкненому ПК**. Для цього потрібен окремий сервер.
- Реальна аналітика власного каналу (CTR, retention) і автоматичне завантаження відео вимагають Google OAuth та окремої інтеграції; цей випуск показує тільки публічну статистику прикладів.
- Графіки світла вручну введені, без гарантії актуальності.
- $5 — це бюджет для OpenAI API LifeHub, інші сервіси мають окремі ліміти/витрати.
