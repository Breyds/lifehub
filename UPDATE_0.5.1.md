# LifeHub 0.5.1 — встановлення через GitHub

Репозиторій: https://github.com/Breyds/lifehub

**Перед оновленням зроби резервну копію через Налаштування → Мої дані → Експортувати JSON.** Не видаляй установлену програму й папку `.git`.

## 1. Скопіюй файли

1. Розпакуй `LifeHub-v0.5.1-Source.zip`.
2. Скопіюй УВЕСЬ вміст архіву в ту папку, з якої раніше виконував `git push`.
3. Підтвердь заміну однакових файлів, **не видаляй `.git`**.

## 2. Перевір локально

У PowerShell у папці проєкту:

```powershell
npm install
npm test
npm run build
```

Якщо хоч одна команда завершилася з помилкою, **не створюй тег**.

## 3. Відправ зміни без релізу

```powershell
git add .
git commit -m "LifeHub 0.5.1 private Telegram, calendar and TikTok audio"
git push origin main
```

На https://github.com/Breyds/lifehub/actions переконайся, що **Validate LifeHub** має зелену галочку.

## 4. Лише після успішної перевірки — реліз

```powershell
git tag v0.5.1
git push origin v0.5.1
```

У Actions збірка **Build and publish LifeHub Windows** повинна бути зеленою. Відкрий Releases і опублікуй Draft, якщо потрібно. Перевір наявність `LifeHub-Setup-0.5.1.exe`, `latest.yml`, `.blockmap`.

## 5. Перевір у програмі

- **Плани:** замість крапок на датах — числа; натисни на дату, щоб відкрити деталі.
- **Telegram:** спочатку відклич раніше опублікований токен у BotFather, створи новий, встав його у LifeHub → Налаштування → Telegram; надішли боту `/link КОД`, тоді натисни «Перевірити прив’язку» в програмі. Перевір `/today`, `/tomorrow`, `/add 19:00 Тест`, `/done 1`.
- **TikTok:** підключи власний AudD-токен у Налаштуваннях. У Музиці відкрий колекцію, натисни «Розпізнати звук» поруч із відео. LifeHub спробує 16 секунд записувати звук Windows та відкриє відео. Якщо автоматичне відтворення заблоковано, натисни Play у браузері. Інші звуки ПК краще вимкнути. Це експериментальна функція й вона може не спрацювати; є запасна кнопка вибору аудіофайлу.
- **ДТЕК:** у Налаштуваннях введи населений пункт, вулицю й будинок, збережи та відкрий сторінку ДТЕК. Дані адреси зберігаються локально, але програма **поки не отримує графік автоматично**.

## Обмеження й безпека

- Telegram-бот приватний і відповідає **тільки прив’язаному Telegram-акаунту**. Нагадування й команди працюють **лише коли запущений LifeHub і є інтернет**. Цілодобовий бот для будь-якої кількості користувачів вимагатиме хостингу.
- Захоплення звуку — **тільки після натискання користувачем**, через Windows loopback. Воно записує загальний звук ПК, не ізольований потік TikTok. У AudD надсилається 16-секундний фрагмент; відео з TikTok напряму не завантажується.
- AudD — окремий платний/лімітований сервіс, **не входить** у $5 OpenAI API.
- Будь-які ключі Telegram, AudD і OpenAI вводяться лише в програмі, **не в GitHub і не в чаті**.
- Зберігай адресу локально; вона може бути включена в експорт резервної копії.
- Реальну роботу системного аудіо, Telegram API та Windows-інсталятора потрібно перевірити на твоєму ПК. Модульні тести не замінюють інтеграційне тестування.
