# LifeHub 0.5.2 — інструкція оновлення

## Перед початком

Встановлений LifeHub не видаляй. Зроби резервну копію через **Налаштування → Мої дані → Експортувати JSON**.

## Як оновити код

1. Розпакуй цей ZIP.
2. Перенеси його вміст у свою локальну папку Git-проєкту LifeHub (ту, з якої запускаєш `git push`). Замінюй файли, **папку `.git` не видаляй**.
3. Відкрий PowerShell у папці проєкту та запусти:

```powershell
npm install
npm test
npm run build
```

4. Якщо помилок немає, завантаж код для незалежної перевірки:

```powershell
git add .
git commit -m "LifeHub 0.5.2 calendar power and news improvements"
git push origin main
```

5. Перевір **Validate LifeHub** на https://github.com/Breyds/lifehub/actions. Якщо перевірка зелена:

```powershell
git tag v0.5.2
git push origin v0.5.2
```

6. Після успішного `windows-installer` опублікуй Draft у https://github.com/Breyds/lifehub/releases.
7. Відкрий встановлений LifeHub, натисни перевірку оновлень. Якщо тиха інсталяція не працює — встанови `LifeHub-Setup-0.5.2.exe` поверх існуючої версії (резервна копія вже зроблена).

## Перевірка функцій

- **Плани / Навчання:** в календарі кількість тільки критичних задач. Клік на дату відкриває всі задачі дня, згруповані за важливістю та повторюваністю.
- **Усі справи:** групування за пріоритетом і повторюваністю для кожної дати.
- **YouTube → Trend Radar:** після підключення `YouTube Data API v3` та натискання «Оновити статистику» кожне знайдене відео має власну кнопку «Відео + перегляди», а за наявності channelId — «Канал». Блок RSS — лише статті та ідеї без підтвердженої статистики.
- **Новини:** при оновленні спроба взяти `og:image` першоджерела, а далі лише ілюстрацію названої теми. Наявність фото залежить від джерела; якщо його нема, відображається нейтральна картка.
- **Налаштування → Графік світла:** введи адресу один раз, натисни «Зберегти й отримати графік». Запит виконується до офіційного сайту ДТЕК усередині LifeHub, результат відображається у програмі. Наступні перевірки — вручну або автоматично після запуску/приблизно кожні 4 години, коли LifeHub відкрито. Захищений сайт може відмовити; помилкових годин LifeHub не вигадує.

**Важливо:** Автоматичне отримання графіка ДТЕК експериментальне, бо DTEK змінює формат і використовує захист від автоматичних запитів. У поточному середовищі немає доступу до живого сайту / Windows, тому перевірка успішного отримання реальної адреси ще попереду. Повне TypeScript-складання теж повинен перевірити GitHub Actions.
