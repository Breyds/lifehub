# LifeHub 0.5.3 — оновлення для Breyds/lifehub

## Перед змінами

1. У встановленій програмі зроби резервну копію **Налаштування → Експортувати JSON**.
2. Закрий LifeHub. Розпакуй архів `LifeHub-v0.5.3-Source.zip` і скопіюй його вміст у папку вихідного коду LifeHub, звідки ти зазвичай робиш `git push`.
3. Замінюй файли, **не видаляй `.git`**, не переносити `node_modules`, `dist`, `release` із ZIP (їх у ньому немає).

## Перевір локально

Відкрий PowerShell у папці проєкту:

```powershell
npm install
npm test
npm run build
```

Якщо `npm run build` видає помилку TypeScript, зупинись і збережи текст помилки — **не створюй тег**.

## GitHub

```powershell
git add .
git commit -m "LifeHub 0.5.3 improvements"
git push origin main
```

У [Actions](https://github.com/Breyds/lifehub/actions) дочекайся **зеленої** перевірки `Validate LifeHub`.

Лише якщо вона успішна:

```powershell
git tag v0.5.3
git push origin v0.5.3
```

У [Releases](https://github.com/Breyds/lifehub/releases) опублікуй Draft. Перевір наявність `LifeHub-Setup-0.5.3.exe`, `latest.yml`, `.blockmap`.

Якщо автооновлення старої версії не вдається — встанови новий EXE поверх старого **без видалення профілю**. Після цього перевір «Налаштування → Оновлення».

## Що перевірити у встановленому 0.5.3

1. **Світло:** окрема вкладка. Введи адресу, натисни «Зберегти адресу», потім «Оновити графік». Перевір, чи є години сьогодні/завтра або конкретне повідомлення про недоступність. Сайт ДТЕК має захист, тому отримання годин не гарантоване; але LifeHub не повинен закриватися.
2. **Календар:** число на даті враховує важливі й критичні задачі. У спливаючому вікні натискай на групи, щоб розгорнути/згорнути.
3. **Усі справи:** перемикай фільтри «Термінові», «Важливі», «Повторювані», «Звичайні».
4. **Новини:** «Цікаво» й «Не цікаво» одразу прибирають картку, «Зберегти» переносить у вкладку «Збережене».
5. **AI-банер:** після підключення OpenAI API натисни відповідну кнопку на одній новині й явно підтвердь витратний запит. Банер має бути позначений як AI-ілюстрація, **не фото реальної події**.

Увага: у поточній версії немає перевіреної, стабільної інтеграції з офіційною системою ДТЕК. Якщо сайт відмовить у доступі, годин не буде. Для діагностики збережи текст повідомлення у вкладці «Світло».
