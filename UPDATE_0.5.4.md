# LifeHub 0.5.4 — Windows-оновлення

## Перш ніж почати

Поточний LifeHub не видаляй. У Налаштуваннях натисни **Експортувати JSON** і збережи резервну копію. Не завантажуй архів історії ChatGPT, Telegram-токен, ключ AudD, OpenAI-ключ або свої особисті файли на GitHub.

## Що стало краще

1. **Вода та інші лічильники.** Для цілі `2,3 л` з'являється кнопка `+0,25` та поле `Додати довільний обсяг` — введи `0,8` і натисни **Додати**. Якщо випив 3,1 л за цілі 2,3 л, програма показує 3,1 л та +0,8 л понад ціль. Шкала лишається заповненою на 100%; факт не губиться. Лічильник можна зменшити кнопкою `−0,25`. Після завершення цілі він не блокує додавання фактично випитого.
2. **Новини.** Перейди в Новини → **Знайти фото для поточних новин**, потім **Оновити стрічку** для отримання прямих Anime News Network-новин. Фото буде лише за наявності в офіційному джерелі або на сторінці конкретної теми. Платні AI-банери залишаються необов'язковими.
3. **ДТЕК.** У вкладці Світло спершу збережи адресу та натисни Оновити. Якщо офіційний сайт повертає 403/вебсторінку замість даних, є резервне поле «Моя черга ДТЕК». Один раз перевір її на офіційному сайті та вибери `1.1`–`6.2`, збережи, натисни Оновити. LifeHub спробує отримати *свіжі дані за чергою* з [публічного дзеркала](https://github.com/Baskerville42/outage-data-ua). Це джерело не підтверджує належність адреси до черги, тому при зміні адреси поле скидається. Якщо джерело застаріло або не дало сьогодні/завтра, програма не вважає години підтвердженими.

## Публікація у твоєму репозиторії

1. Розпакуй ZIP **у вже існуючу локальну папку Git-проєкту**, замінивши файли. Папку `.git` не видаляй, `node_modules`, `release` та `dist` вручну не копіюй.
2. У PowerShell у корені LifeHub:
   ```powershell
   npm install
   npm test
   npm run build
   ```
3. Лише якщо ці команди **без помилок**, завантаж зміни:
   ```powershell
   git add .
   git commit -m "LifeHub 0.5.4 progress and news fixes"
   git push origin main
   ```
4. У https://github.com/Breyds/lifehub/actions перевір **Validate LifeHub**. Якщо збірка успішна:
   ```powershell
   git tag v0.5.4
   git push origin v0.5.4
   ```
5. Відкрий https://github.com/Breyds/lifehub/releases і опублікуй створений Draft `v0.5.4`. Установлений LifeHub повинен запропонувати нову версію. Якщо автоматичне оновлення все ще не працює, запусти `LifeHub-Setup-0.5.4.exe` поверх наявної інсталяції після резервного копіювання.

## Межі перевірки

Модульні тести та синтаксичні перевірки пройдені. **Windows-інсталятор, живі RSS-фотографії та отримання графіка за чергою у твоєму регіоні ще не підтверджені на реальній Windows-машині**. Якщо GitHub Actions покаже помилку, не створюй/не публікуй тег, а надішли лог.
