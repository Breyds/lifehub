# LifeHub 0.6.0 — оновлення інтерфейсу «Сьогодні»

## Що нового
- Єдина глобальна кнопка AI-помічника у верхній панелі; дубльований великий AI-блок видалено.
- Велика центральна панель справ: час, колір важливості, категорії з іконками, прогрес і пряме редагування.
- Перемикання вчора / сьогодні / завтра з коректною назвою обраного дня. Повернення на сьогодні окремою кнопкою.
- Компактний блок завтрашніх або важливих справ.
- Новий календар вибору дати; 12-годинне колесо вибору часу з хвилинами та AM/PM. Вибір часу активний навіть якщо раніше була позначка «без конкретного часу».
- Довільна тривалість у хвилинах або годинах, кольорові рівні важливості (звичайне, важливе, дуже важливе, критичне).
- Відстеження: галочка, кількісна ціль або ручний облік хвилин. Останній режим не є фоновим таймером.
- Кнопка змінити прогрес розгортає компактний редактор кількості (наприклад, 0,8 л).
- Особистий JSON із наших чатів: **Налаштування → Особистий JSON LifeHub** → перегляд, прапорці, захист від дублікатів, ручне підтвердження дат для справ.
- Чинна ручна AI-генерація банерів новин лишається опціональною та маркується як AI-ілюстрація; нічого не генерується автоматично.

## Встановлення
1. У вже встановленому LifeHub експортуй резервну копію (**Налаштування → Мої дані → Експортувати JSON**).
2. **Не видаляй** встановлений LifeHub, `.git` та дані `%APPDATA%/lifehub-personal`.
3. Розпакуй цей ZIP і скопіюй його **вміст** у твій локальний Git-проєкт LifeHub із заміною файлів. `.git` залиш як є.
4. У цій папці в PowerShell введи:
   ```powershell
   npm install
   npm test
   npm run build
   ```
5. **Якщо є помилка збірки, не публікуй тег** — збережи текст помилки для діагностики.
6. Якщо все зелене:
   ```powershell
   git status
   git add .
   git commit -m "LifeHub 0.6.0 focused daily dashboard"
   git push origin main
   ```
7. Відкрий https://github.com/Breyds/lifehub/actions і переконайся, що **Validate LifeHub** успішно завершився.
8. Лише тоді:
   ```powershell
   git tag v0.6.0
   git push origin v0.6.0
   ```
9. Перевір **Build and publish LifeHub Windows** у Actions, потім опублікуй Draft у https://github.com/Breyds/lifehub/releases. У встановленому LifeHub перевір оновлення.

## Імпорт профілю
- Вибери файл `LifeHub-Personal-Import.json` із попередньої розмови.
- За замовчуванням відмічаються лише проєкти з підтвердженим статусом; чернетки справ не вибрані.
- Для кожної вибраної чернетки справи **обов’язково вибери дату**. При імпорті ніщо не видаляється або не перезаписується.
- API-токени й ключі не імпортуються. Файл і персональні резервні копії додані до `.gitignore`.

## Стан перевірки
- Локально: 88/88 модульних тестів, React/TypeScript синтаксис успішно розібраний, JavaScript у Electron перевірено.
- Тут не вдалося виконати повне `npm install`, тому **повна збірка React/Electron і поведінка інсталятора в Windows ще не підтверджені**. Запуск `npm run build` і GitHub CI є необхідними перевірками.
- Telegram, TikTok, YouTube, AudD, ДТЕК і оновлення залишено з попередніх версій, але їхній повний регресійний тест із живими сервісами на цьому середовищі неможливий.
- Публікація GitHub без наданого доступу до репозиторію не виконувалась.
